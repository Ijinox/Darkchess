## ♟️ Darkchess 4.0

Jeu d'échecs complet en Python / PySide6, avec IA intégrée (aucun moteur externe requis).

### Fonctionnalités clés
- 🤖 IA Aurora à 7 modes : Agressif, Défensif, Équilibré, Chaotique, Tacticien, Stratège, Polyvalent
- 🎮 Profil IA persistant : XP, niveau, caractéristiques évolutives, mémoire active
- ⚡ Simulation rapide : N parties IA vs IA en quelques secondes
- 🎨 3 thèmes visuels : Clair, Sombre, Enfer
- 📄 Export PGN compatible lichess.org
- 🧩 Architecture modulaire, tests unitaires, CI GitHub Actions
- Ouvert pour business/collaboration open source.... licence MIT dessus juste dites que ça vient de moi c'est tout...
