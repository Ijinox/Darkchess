# Darkchess

Un jeu d'échecs complet en Python / PySide6 avec une IA intégrée.
Développé en workflow assisté par IA (Kimi + DeepSeek) sur une base
de moins de 2000 lignes.

**Auteur** : Adrian Antoniak ([@Ijinox](https://github.com/Ijinox))
**Licence** : MIT — libre d'utilisation, de modification et de
redistribution, à condition de conserver la mention d'auteur originale.

## ♟️ Darkchess 4.0

### Fonctionnalités
- 🤖 IA Aurora à 7 modes : Agressif, Défensif, Équilibré, Chaotique,
  Tacticien, Stratège, Polyvalent
- 🎮 Profil IA persistant : XP, niveau, caractéristiques évolutives,
  mémoire active
- ⚡ Simulation rapide : N parties IA vs IA en quelques secondes
- 🎨 3 thèmes visuels : Clair, Sombre, Enfer
- 📄 Export PGN compatible lichess.org
- 🧩 Architecture modulaire, tests unitaires, CI GitHub Actions

### Installation

pip install -r requirements.txt
